# Without this file nginx's SPA fallback answered /robots.txt with index.html,
# so crawlers fetched a full HTML document where a plain-text policy was
# expected. Cloudflare prepends its own managed directives to this response;
# those allow search crawlers and only block AI-training bots, so the two are
# compatible.
#
# The Sitemap line is filled in from LANDING_FRONT_URL by docker-entrypoint.sh,
# and removed when that is unset.

User-agent: *
Allow: /

Sitemap: __LANDING_FRONT_URL__/sitemap.xml
